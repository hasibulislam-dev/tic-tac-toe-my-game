Tic Tac Toe Game 🎮

About the Project

This is a simple and interactive Tic Tac Toe game developed using HTML, CSS, and JavaScript. Two players can play against each other on a 3×3 game board.

Features

Two-player gameplay

Interactive 3×3 game board

Automatic winner detection

Draw detection

Restart Game option

Player score tracking

Technologies Used

HTML

CSS

JavaScript

How to Play

Player X starts the game.

Player O takes the next turn.

Players take turns selecting empty cells.

The first player to match three symbols horizontally, vertically, or diagonally wins.

If all cells are filled without a winner, the game ends in a draw.
